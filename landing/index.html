CONÇU POUR L'EFFICACITÉ

Tout ce dont vous avez besoin.
Sans le superflu.

Zéro Ligne de Commande

Démarrez, stoppez, redémarrez et créez des conteneurs isolés ou déployez des stacks complètes depuis une interface graphique tactile et fluide.

UI tactile & responsive

Éditeur Compose en Direct

Modifiez vos fichiers docker-compose.yml directement dans un éditeur de code intégré, et redéployez la stack en un clic sans changer de fenêtre.

Syntaxe YAML & Hot-Reload

Webhooks Discord Granulaires

Fini le spam ! Configurez des alertes précises par stack ou conteneur ciblé. Incluez l'uptime, l'état de santé et les rapports périodiques.

Ciblage strict & Embeds riches

Mise à jour 1-Clic

Dès qu'une nouvelle image Docker est disponible, mettez à jour votre conteneur ou toute la stack Compose avec pull && recreate automatique.

Zéro interruption inutile

Démarrage Automatique (Multi-OS)

Activez Dock (1) en tâche d'arrière-plan dès l'allumage de votre ordinateur, nativement sous Linux (systemd), macOS (Launchd) ou Windows (Dossier Démarrage).

Notes de version officielles

v26.1 Dernière version
Version 26.1 • Release Initiale
  • ● Application Desktop Native : Packagée avec Electron pour une expérience fluide hors navigateur.
  • ● Écran de Boot & Onboarding Nothing OS : Séquence de boot hardware avec diode pulsée et visite guidée interactive en 5 étapes.
  • ● Mise à jour 1-clic des Stacks et Conteneurs : Déclenchez docker compose pull && up -d ou le renouvellement de conteneur directement depuis l'interface.
  • ● Filtrage Granulaire Webhook Discord : Résolution stricte du périmètre pour que les alertes ne touchent que les conteneurs et stacks sélectionnés.
  • ● Sélecteur de Stacks sur le Dashboard : Affichez uniquement un cluster ou une stack sur la grille principale en 1 clic.
