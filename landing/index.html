CONÇU POUR L'EFFICACITÉ

Tout ce dont vous avez besoin.
Sans le superflu.

Zéro Ligne de Commande

Démarrez, stoppez, redémarrez et créez des conteneurs isolés ou déployez des stacks complètes depuis une interface graphique tactile et fluide.

UI tactile & responsive

Éditeur Compose en Direct

Modifiez vos fichiers docker-compose.yml directement dans un éditeur de code intégré, et redéployez la stack en un clic sans changer de fenêtre.

Syntaxe YAML & Hot-Reload

Webhooks Discord Granulaires

Fini le spam ! Configurez des alertes précises par stack ou conteneur ciblé. Incluez l'uptime, l'état de santé et les rapports périodiques.

Ciblage strict & Embeds riches

Mise à jour 1-Clic

Dès qu'une nouvelle image Docker est disponible, mettez à jour votre conteneur ou toute la stack Compose avec pull && recreate automatique.

Zéro interruption inutile

Autostart Silencieux (Systemd)

Configurez le démon Dock (1) pour démarrer en tâche de fond dès l'allumage de votre machine Linux grâce à loginctl enable-linger.

Démarrage sans session requise

Palette de Commandes ⌘K

Gardez les mains sur le clavier. Cherchez n'importe quel service par port, nom ou image, basculez de thème et consultez les logs instantanément.

Clavier d'abord (Keyboard First)
